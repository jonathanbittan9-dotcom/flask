About

This tiny app demonstrates the core Flask features:

  • Routes — URLs mapped to Python functions with @app.route.
  • Templates — HTML files in templates/ rendered with render_template.
  • Inheritance — base.html defines blocks, other templates fill them.
  • Forms + POST — submit data, then redirect (Post/Redirect/Get).
  • url_for — build URLs from function names, never hard-coded.
  • flash — one-time messages that show on the next page.
  • Static files — CSS served from static/.
  • Error handlers — custom 404 page.
