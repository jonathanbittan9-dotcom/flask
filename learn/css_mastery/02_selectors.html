Try it

Change .card > h2 to just .card h2 (drop the >) — nothing visibly changes here because the h2 IS a direct child. Now imagine a <div> wrapping the h2 inside the card: .card h2 would still match it, .card > h2 would not. That's the whole difference between "descendant" and "direct child."
