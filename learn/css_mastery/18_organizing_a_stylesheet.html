File structure and @import cost

A reasonable structure once one style.css stops being enough:

static/css/
  tokens.css       /* variables only */
  base.css         /* element defaults, no classes */
  components/
    card.css
    navbar.css
    button.css
  utilities.css    /* small single-purpose helpers */
  style.css        /* imports the rest, in dependency order */

@import inside CSS is the simplest way to combine those files, but each @import is its own blocking network request in the browser unless bundled — fine for a handful of files in a learning project, worth switching to a build step (or Jinja's own {% include %}-adjacent tooling) once there are many. For hello.py-scale projects, plain @import or even one hand-organized file (with the section comments below) is genuinely fine.

A reset or normalize layer

Browsers ship inconsistent default margins/font-sizes on h1-h6, lists, and form elements. A small reset removes the inconsistency before your own rules apply:

*, *::before, *::after { box-sizing: border-box; }         /* lesson 4 */
body, h1, h2, h3, p, ul, ol { margin: 0; }
ul, ol { padding: 0; list-style: none; }
img, video { max-width: 100%; display: block; }
button, input, textarea { font: inherit; }                 /* form elements don't inherit font by default */

Documenting a component

A short comment block above a non-obvious component pays for itself the first time someone (including future you) has to change it:

/* .card — a bordered content block used on the home page and any
   listing page. Modifiers: .card--featured (orange accent, used for
   the single highlighted item at the top of a list).
   Depends on: --accent, --space-md (tokens.css). */
.card { ... }

Styling your Flask project end to end

The actual lab for this lesson — apply everything above to hello.py:

  1. Create static/css/style.css (lesson 1 covers linking it with url_for).
  2. Add the box-sizing + minimal reset from above at the top.
  3. Define your tokens: 2-3 colors, a spacing scale, one radius value — as :root custom properties (lesson 16).
  4. Style templates/home.html's actual elements using a class per component (a card for the greeting, a list style for hobbies) — class names, not element selectors, per lesson 2.
  5. Run python hello.py, visit the page, and hard-reload (Ctrl+Shift+R) until it looks intentional — this is genuinely the whole discipline: tokens once, components built from them, nothing more specific than it needs to be.

That's the full 18-lesson track. js_mastery/20_fetch_flask_api.js is the natural next step once this styling pass is done — wiring JS into the same page.
