clamp(1.2rem, 1rem + 2vw, 2.4rem) — never smaller than 1.2rem, never larger than 2.4rem, fluid in between.

Rules of thumb

  • Font sizes: rem.
  • Spacing: rem, from a small scale (0.25 / 0.5 / 1 / 1.5 / 2 / 3).
  • Borders and hairlines: px.
  • Text column width: ch, around 60–75 characters.
  • Fluid type or spacing: clamp().
