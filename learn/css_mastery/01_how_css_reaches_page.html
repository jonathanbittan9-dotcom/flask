How CSS reaches the page

This heading is styled by the internal <style> block above — teal color, 2rem size. Open this file in a text editor and read the <style> block; it's the real lesson content.

This paragraph is styled INLINE, with a style="..." attribute directly on the tag. It works, but it can't be reused anywhere else, and — as lesson 3 explains — it beats almost anything in your stylesheet, which is exactly why it's discouraged for anything beyond a one-off experiment.

This box has class="card". Try it yourself: change the border color and border-radius values above, save, and reload (Ctrl+Shift+R to force-bypass the cache — browsers cache CSS aggressively, and this wastes more beginner time than any other single thing in CSS).

Try breaking it

In the <style> block, delete the closing } of the h1 rule and reload. The h1 rule will swallow everything below it, and .note's styling disappears — CSS fails silently, no error, just missing styles. That's why a syntax-highlighting editor (which visibly shows unmatched braces) is worth having before you write much more CSS than this.
