Custom properties

This box is built entirely from --accent, --accent-wash, --radius and --space-md, defined once on :root.

A fallback value — this text uses a variable that was never defined, so var()'s second argument kicks in:

Styled by var(--this-was-never-defined, #A96A22)

This box redefines --accent and --accent-wash LOCALLY — everything using var(--accent) inside it picks up orange instead of teal, without touching the global values used everywhere else on the page.

Try your OS/browser's dark mode toggle and reload this page — :root's --accent/--accent-wash swap to different values via prefers-color-scheme, and every var(...) reference updates automatically, no selectors duplicated.

Reading and setting them from JavaScript

// read a custom property's current value
getComputedStyle(document.documentElement).getPropertyValue('--accent');

// set one at runtime — every var(--accent) on the page updates live
document.documentElement.style.setProperty('--accent', '#A96A22');

This is how a JS-driven theme switcher usually works — one JS line flips a handful of custom properties instead of toggling classes on every styled element individually.
